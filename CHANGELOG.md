# Changelog

## 0.2.0
- Replaced vanilla placeholder texture references with original DLavie nature art.
- Added original bark end-cap, leaf, fern, meadow grass, clover, heather and nettle textures.
- Enabled Vibrant Visuals PBR capability.
- Added PBR texture sets with roughness and foliage subsurface properties.
- Added three custom foliage geometries.
- Reworked oak generation around `fancy_trunk` procedural branches.
- Added two additional woodland oak silhouettes.
- Expanded forest-floor vegetation.
- Added pack icon and English block names.
- Raised package version to 0.2.0 while retaining Minecraft Bedrock 1.26.45+ minimum.
